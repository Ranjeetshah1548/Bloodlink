How matching works

Every request moves through the same pipeline, and the status is visible to the recipient the whole way through.

1
Request created

A recipient specifies a blood group, units required, and urgency.

2
Hospital selected

Only verified hospitals — picked from the map/list, never typed freely.

3
Compatibility checked

Fixed ABO/Rh rules determine which donor blood groups are eligible.

4
Eligible donors found

Filtered further by availability and minimum donation interval (90 days).

5
Donors ranked

Distance is computed from lat/long, and a Random Forest model scores response likelihood.

6
Request sent

The top-ranked donors are notified.

7
Donor responds

Each notified donor can accept or decline.

8
Request fulfilled

Once resolved, the donation is recorded in the donor's history.

The ML response-likelihood score is a prioritization signal only — never a guarantee that a donor will respond, and never a factor in medical eligibility.
