About BloodLink

BloodLink is a smart blood donation and donor matching platform. It connects people who need blood at a verified hospital with nearby, eligible, available donors — using medically verified compatibility rules first, and a machine learning model second, purely to prioritize outreach among donors who are already eligible.

Why a two-stage approach?

Whether a donor's blood group can safely help a recipient is a fixed medical fact — it is never inferred by a model. BloodLink encodes ABO/Rh compatibility as a fixed rules table. Only after that filter narrows the pool does a trained Random Forest classifier estimate how likely each eligible donor is to respond, using distance, donation history, and availability. That score is a prioritization signal, never a promise.

Data & privacy

All accounts, profiles, requests and responses are stored in a relational MySQL database. Passwords are hashed, sessions use JWTs, and phone numbers go through an OTP-ready verification flow before an account is treated as fully verified.
