How matching works

  1. Compatibility rules find eligible donor blood groups
  2. Availability & donation-interval filters narrow the pool
  3. Distance to hospital is calculated (lat/long)
  4. A trained Random Forest scores response likelihood
  5. Donors are ranked and notified in order

Built for the real workflow

Verified hospitals only

Every blood request is tied to a hospital that has been verified by an administrator — no free-text hospital entry.

Transparent prioritization

The response-likelihood score is a prioritization signal, never a guarantee. Medical eligibility always comes first, from fixed compatibility rules.

Full request tracking

Recipients can watch a request move from created through hospital selection, matching, donor response, and fulfillment.
